# Historial de sesiones

> Append-only. Al cerrar cada sesión, copia el bloque "Sesión en curso" de `current.md`
> al final de este archivo bajo un encabezado `## YYYY-MM-DD HH:MM — <título>` y deja
> `current.md` con el template vacío.

> Formato sugerido por entrada:
> - **Spec / tareas tocadas**: IDs y descripciones.
> - **Archivos modificados**: lista.
> - **Resultado de verificación**: `npm run verify` (OK / fallos concretos).
> - **Commits creados**: SHAs cortos + mensaje.
> - **Pendiente para próxima sesión**: lo que se quedó a medias.
